# One Word for the Boss

An entry for the make.fun bounty [One Word for the Boss](https://make.fun/bounty/u-swift-badger-44-one-word-for-the-boss-6b48c735?utm_source=github&utm_medium=readme&utm_campaign=u-swift-badger-44-one-word-for-the-boss-6b48c735): a tiny Python program that writes exactly one word describing a boss — **Hoverer** — to `/output/entry.txt`. No phrase, no caption, no explanation. The word is the whole entry.

## Run it

```sh
python3 main.py
```

This writes the single word `Hoverer` to `/output/entry.txt` (no trailing newline), then reads the file back and checks it against the competition gate: UTF-8 text, 1–30 characters, one word, no whitespace, no newline.
